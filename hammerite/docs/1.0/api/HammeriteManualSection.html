HammeriteManualSection

Editor. Inherits RefCounted

One section of the manual: an addon's or a game's directory of pages. What HammeriteManual.sections() hands out is a copy; a section is changed by registering it again.

Properties

TypeNameDefault
StringNameid&""
Stringtitle""
intorder0
PackedStringArraydirectoriesPackedStringArray()

Property descriptions

id

var id: StringName = &""

What its pages' paths begin with, <id>/<page>.md.

title

var title: String = ""

What the index heads it with.

order

var order: int = 0

Where it stands in the index, lowest first; negative stands after every section given one.

directories

var directories: PackedStringArray = PackedStringArray()

Where its pages are read from, its own directory first. A page found in two is the first one's.
