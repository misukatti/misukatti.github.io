HammeriteUnknownData

Core: files, names and extension. Inherits Resource

An object of a class this game does not have, carried through a data file unread (#124).

A map outlives the addons that wrote into it: a baked graph an addon kept in HammeriteMap.custom_data is still in the file after the addon is disabled. Refusing the map over it locked the author out of their level; dropping it destroyed the addon's work the next time the map was saved. This stands where the object stood, holding what the file said about it, and HammeriteDataFile writes it back as it was. Nothing here is exported, so a Godot resource file cannot carry one: only a data file can. HammeriteMap.unknown_classes() says which a map is carrying.

The version of that class it was saved at (HammeriteDataFile.version_of()).

Its values as the file held them. A reference to another object is a mark naming an entry of references, since record numbers change from one save to the next.
