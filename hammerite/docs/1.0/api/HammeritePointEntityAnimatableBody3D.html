HammeritePointEntityAnimatableBody3D

Core: entities. Inherits AnimatableBody3D

A point entity that MOVES and that the world can collide with: a door leaf, a lift, a drawbridge.

Same interface as HammeritePointEntityNode3D, on a body the physics server knows about. Reach for it when the thing is driven from script and has to push the player around; reach for HammeritePointEntityNode3D when it only needs to be somewhere. It is not sized for you. Godot does not promise to collide a scaled body, so a type that can be sized hands scale to apply_entity_property() and the subclass sizes its own meshes and collision shapes, as HammeritePropModel sizes its collider's points.

update_properties()

func update_properties() -> void

Apply every property the entity's type declares, as the entity holds it or as the type defaults it: a map saved before a property existed has no key for it, and its entities read the type's default. set_entity() calls it. Override it, calling super(), for what wants every property applied first - gathering the probes that light the node once it knows where it stands.

trigger()

func trigger(_impulse = null) -> void

Do whatever this entity does when triggered. impulse is whatever the one triggering it handed over - null from the editor's Trigger, a HammeriteTrigger's target_impulse - and what it means is the entity's to say: a light might read a bool as on or off and toggle on null, a lift a floor number.

get_actions()

func get_actions() -> Dictionary[StringName, String]

The actions this entity offers in the editor's runtime panel, as id -> label. Every entity that says it can be triggered gets Trigger for nothing. Override to add more, and call super() unless you mean to drop it.
