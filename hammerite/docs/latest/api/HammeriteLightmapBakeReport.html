HammeriteLightmapBakeReport

Core: lighting. Inherits RefCounted

What each pass of a bake did to the light: how much energy the texels and probes held after it, static and switchable, and how many held any. Left on HammeriteLightmapper.bake_report when a bake ends, to ask whether light got where it should - "the probes gathered in GATHER", "a bounce added light in DISTRIBUTE". Totals only; the texels and probes themselves are live on the map.

Compact one-line-per-pass summary for logs / test failure output.

class PassSnapshot

One completed pass. dynamic fields sum the 4 light slots (RGBA); static fields sum the single RGB. NOTE: kind is stored as a plain int (a Kind value). GDScript inner classes cannot see the outer class's Kind enum unqualified, so the default is the literal 0 (== Kind.DIRECT) and the name lookup lives in the outer class's static kind_name().
