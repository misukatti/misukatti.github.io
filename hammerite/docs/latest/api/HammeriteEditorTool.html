HammeriteEditorTool

Editor. Inherits RefCounted

Base class for an editor tool: the one thing the author's clicks and keys go to in the viewports.

A tool is made for one use and thrown away. Construct it with the HammeriteMapEditor and hand it to HammeriteMapEditor.set_active_tool(). While it is active and a view has focus the editor calls _tool_input() for each event and _tool_process() each frame; when it is switched away from, or calls request_exit(), the editor calls _tool_exit() and then release(). Anything it draws over the level goes into gizmos from _tool_process(), every frame.

Method descriptions

release()

func release() -> void

Let go of the tool's own history. UndoRedo holds every reference-counted object whose method it records, this tool's included, so a tool with any history would outlive the editor's last use of it; the editor calls this when it lets a tool go.

surface_facing_viewer()

static func surface_facing_viewer(plane: Plane, view_direction: Vector3) -> Plane

plane turned towards whoever is looking along view_direction: the side of the surface the author can see, which is the side anything built or placed on it belongs on. Not the face's own normal. That points out of the face's brush, and a room is an air brush, so on a room's floor it points down into the rock: what followed it built stairs downwards into solid and put prefabs under the floor. A filled brush is meshed from both sides, so asking the brush which side is open cannot be right for all of them; the side being looked at always is.

Method descriptions

set_title()

func set_title(title: String) -> void

Sets the text at the top of the popup.

add_separator()

func add_separator() -> void

Adds a horizontal rule below what is there so far.

add_field()

func add_field(name: StringName, default_value, label: String, disabled: bool = false) -> void

Adds a labelled field named name, its control chosen by default_value's type: a SpinBox for int or float (range ±65536), a LineEdit for String, a CheckBox for bool. Any other type is an error. Changes emit value_changed.

add_button()

func add_button(name: StringName, label: String) -> Button

A tool parameter that is an action rather than a value, e.g. rotating what is being drawn. Emits button_pressed with name.

add_note()

func add_note(text: String) -> Label

A line of explanation, for when what a tool does depends on state that is not in the popup.

has_field()

func has_field(name: StringName) -> bool

Whether a field named name has been added.

set_value()

func set_value(name: StringName, value) -> void

Shows value in field name without emitting value_changed. Does nothing for a name with no field.
