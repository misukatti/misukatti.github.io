Props

A prop is a model standing in the level: a chair, a crate, a torch bracket. The models are your game's own, found where it keeps them.

Place props

  1. Press Cmd Shift E, or click the chair on the toolbar. The prop browser opens in the left panel, and the Prop panel at the bottom right.
  2. Click a model. Type in the filter field to find one by name; several words narrow it to names with all of them.
  3. Point at a surface in a view. The model shows where it will stand, resting on the surface. In the 2D views it shows as its box.
  4. Click to place it. Click again for more.
  5. Press Esc to leave the tool.

Or drag a model from the browser into a view.

Rotation and Scale in the panel set how the next prop stands. A prop is moved along the surface to the grid, and never off the surface.

Each placement is one undo step.

A model is pictured the first time it scrolls into view, so a long list fills in as you go.

Select and move placed props

  1. In the prop tool, press Tab or click Select placed.
  2. Click a prop to select it. The inspector shows it too.
  3. Drag it across any surface. It rests on whatever it is over.
  4. Let go to keep it there. Change its Rotation and Scale in the panel.
  5. Press Tab to go back to placing. Picking a model in the browser does the same.

Each drag and each change is one undo step.

Props are prop_model entities, so you can also select them with the select tool and move, rotate and scale them as anything else. See Entities.
