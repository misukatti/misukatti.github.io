Keyboard reference

Cmd is ⌘ on macOS and Control on Windows and Linux. In a key combination such as Ctrl G, Ctrl is Control on macOS and Alt on Windows and Linux. Held while you click, drag or fly, Ctrl is Control everywhere.

A tool other than Select takes the plain keys while it runs, so a letter goes to the tool rather than to the menu below. Press Esc to leave the tool first. Cmd, Ctrl and Alt combinations, F-keys, Tab, =, -, and the view toggles marked any tool work in every tool.

Keys do nothing while you are typing in a field. Tab and Shift Tab move from one field of a panel to the next, and Esc leaves the field, so the next Esc clears the selection or leaves the tool. Clicking in a view leaves the field too.

These are the keys the editor comes with. You can change any of them: see Changing a key.

Changing a key

Help → Keyboard Shortcuts… lists every command with its keys, the keys a tool has while it runs, and the keys you hold down, such as the ones you fly with. Type in the search field to find a command by its name or a key by what it is, such as F5.

  1. Double-click a command, or select it and press Change….
  2. Press the key you want for it, with any of Cmd, Ctrl, Alt and Shift. Esc leaves it as it was.

If another command already has that key, the window says which and asks. Replace gives the key to this command and takes it from the other. Cancel changes nothing. A key that a tool has while it runs is only that tool's, so it can also be a key of a command outside the tool.

Clear leaves a command with no key. Reset gives it back the keys it came with, and Reset All does that for every command. A key you changed is shown in colour, and its tooltip says what it was.

Your keys are saved with the editor's layout, and they are the same in every map. The menus, the toolbar's tooltips and the command launcher show your keys at once. The tables on this page show the keys the editor comes with.

The / that opens the command launcher is typed, not pressed, and cannot be changed here.
