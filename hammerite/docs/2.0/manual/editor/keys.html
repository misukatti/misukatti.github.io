Keyboard reference

Cmd is ⌘ on macOS and Control on Windows and Linux. In a key combination such as Ctrl G, Ctrl is Control on macOS and Alt on Windows and Linux. Held while you click, drag or fly, Ctrl is Control everywhere.

A tool other than Select takes the plain keys while it runs, so a letter goes to the tool rather than to the menu below. Press Esc to leave the tool first. Cmd, Ctrl and Alt combinations, F-keys, Tab, =, -, and the view toggles marked any tool work in every tool.

Keys do nothing while you are typing in a field.
