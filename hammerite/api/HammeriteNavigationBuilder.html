HammeriteNavigationBuilder

Navigation. Inherits RefCounted

Derives the walkable ground of a compiled map.

There is no painting step and no voxelisation. In a subtractive world the compiler has already answered the question a navigation baker normally spends all its effort on: it knows where the air is, it has cut each room's surfaces into convex pieces, and it has punched the doorways out of them. What is left is to pick the pieces you could stand on and measure them. Which way is up. An air brush's face normals point OUT of the room, so a room's FLOOR is the boundary wall whose normal points DOWN - into the rock beneath. The genuinely upward-facing surfaces in a room are the tops of detail brushwork standing in it (a crate, a ledge), which are not part of the cell boundary at all. Two sources, opposite tests; easy to get backwards. Obstructions are not subtracted, they are measured. There is no pass that removes the footprints of things standing in the way. Instead every patch of ground carries the free height above it, and something standing on the floor is simply ground with no headroom. That falls out the same computation, and it gets right the case a footprint subtraction gets wrong: a chandelier must not block the floor beneath it. The ground IS cut where the free height above it changes, though - by a ceiling that drops, or by the underside of something hanging over part of it - because one patch carries one headroom, and a number that describes only the middle of a patch is a number an agent profile cannot safely filter on.

Constants

MAX_WALKABLE_SLOPE_DEGREES

const MAX_WALKABLE_SLOPE_DEGREES = 46.0

Ground steeper than this is a wall, not a floor.

MAX_MEASURED_CLEARANCE

const MAX_MEASURED_CLEARANCE = 512.0

Headroom is not measured beyond this - nothing walks that tall, and a room open to the sky has no ceiling to find.

HEIGHT_EPSILON

const HEIGHT_EPSILON = 0.5

Two surfaces this close in height are the same surface for the purpose of measuring what stands on what. Absorbs the float noise in coincident planes.

CEILING_NORMAL_MIN_Y

const CEILING_NORMAL_MIN_Y = 0.7

A boundary wall facing up more than this is a ceiling - something that stops an agent standing up - rather than a wall it stands beside.

CEILING_BUCKET_SIZE

const CEILING_BUCKET_SIZE = 256.0

Plan-grid bucket size for the ceiling index, matching core's cell hash.

WIDEST_MEASURED

const WIDEST_MEASURED = 1024.0

The widest a patch is measured as. Past this nothing is looked for: it is wider than any body.

MAX_CEILING_SPLITS

const MAX_CEILING_SPLITS = 24

Most pieces one patch of ground is cut into by the ceilings over it. A guard against pathological brushwork; past it the remainder takes the lowest ceiling found, which errs towards keeping agents out rather than letting them in.

NAV_ROLE_KEY

const NAV_ROLE_KEY = &"nav_role"

HammeriteEntity property naming what a prop does to navigation. Props are meshes, and a mesh is only triangles - nothing here can tell a table you walk on from a statue you walk round from a banner you walk through. HammeriteBrush geometry is semantic and needs no marking; props are not and do.

ROOM_ASKED_ABOVE

Heights above the ground, in map units and in the order asked, at which the room over it is looked for.

STRIDE

The rise a floor goes on over: HammeriteNavigationLinkBuilder.MAX_STEP_HEIGHT, and what two heights that should be one differ by.

Property descriptions

warnings

var warnings: String[] = []

What the last build could not do. An unmarked prop is inert to navigation, which is the cost of marking being explicit, so the build says how many there were rather than leaving it to be discovered by an agent walking through a statue.

progress

var progress: HammeriteCompileProgress = null

Told how far build_surfaces() has got, when it runs as part of a compile. It stops early once this says it was cancelled.

native_ground

var native_ground: bool = <unknown>

Whether the native kernel measures the ground's widths, as _floor_edges() and _furthest_from() do, and splits its edges for the meshes, as HammeriteNavigationMeshEmitter._split_edges() does. Settable, so a suite can build both ways.

Method descriptions

build_surfaces()

func build_surfaces(map: HammeriteMap) -> HammeriteNavigationSurface[]

Every patch of ground in map an agent could conceivably stand on, measured.

obstruction_bounds()

static func obstruction_bounds(map: HammeriteMap) -> AABB[]

Everything standing in the rooms, as world-space bounds. Exposed because measuring the ground is not the only thing that has to know about a crate: HammeriteNavigationLinkBuilder asks whether the air between two ledges is really empty, and the crate that divided the floor into those two patches in the first place is exactly what would otherwise be jumped straight through. Warnings are dropped here - the caller that BUILT the ground has already reported them, and saying it twice per bake helps nobody.
