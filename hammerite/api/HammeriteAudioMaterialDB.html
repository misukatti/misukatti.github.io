HammeriteAudioMaterialDB

Audio. Inherits RefCounted

Database of acoustic materials and texture-to-material mapping

This database provides acoustic properties for materials based on texture names. A texture is matched to the first material whose name occurs anywhere in it (e.g., "stone_wall_01" -> "stone"). The acoustic graph builder makes its own with the defaults below, so a room's Auto reverb preset is sampled against these whatever a game adds to an instance of its own.

Property descriptions

materials

var materials: Dictionary = {}

Dictionary of material_name -> HammeriteAudioMaterial. Keys are lower case; add through add_material() rather than writing here.

default_material

var default_material: HammeriteAudioMaterial

Fallback material for unknown textures

Method descriptions

get_material()

func get_material(texture_name: String) -> HammeriteAudioMaterial

Get acoustic material for a given texture name, ignoring case: an exact material name, else the first material, in the order they were added, whose name is a substring of it - so "sandstone" is stone, and "textile" is tile. default_material when nothing matches.

get_material_by_name()

func get_material_by_name(material_name: String) -> HammeriteAudioMaterial

Get material by exact name (for direct lookups), ignoring case; default_material when there is none, so use has_material() to tell.
