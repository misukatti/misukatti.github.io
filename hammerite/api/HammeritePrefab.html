HammeritePrefab

Core: the map. Inherits Resource

A prefab containing brushes and entities.

Prefabs are reusable templates that can be instantiated in maps. Each instance tracks its source prefab via prefab_id.

Property descriptions

prefab_id

var prefab_id: int = 0

Unique identifier for this prefab across prefab sets, nonzero once assigned (the editor draws it from ResourceUID.create_id()). Brushes and entities placed from it carry it as their prefab_id.

prefab_name

var prefab_name: String = "Untitled Prefab"

Display name of the prefab. Must be non-empty for is_valid().

brushes

var brushes: HammeriteBrush[] = []

Brushes contained in this prefab, in prefab-local space (relative to the instance transform).

entities

var entities: HammeriteEntity[] = []

Entities contained in this prefab, their origins in prefab-local space.

preview_texture

var preview_texture: Texture2D = null

Preview texture for the prefab browser, set by generate_thumbnail(). Saved with the prefab.

tags

var tags: String[] = []

Tags for organizing and searching prefabs. Stored only; nothing in Hammerite reads them yet.

category

var category: String = ""

Category for organization in the browser.

origin_offset

var origin_offset: Vector3 = Vector3(0, 0, 0)

The map-space centroid of the content the prefab was made from, recorded when it was created. Informational: placing an instance does not read it.

aabb

var aabb: AABB = AABB(0, 0, 0, 0, 0, 0)

Axis-aligned bounds of the prefab content in prefab-local space. Recomputed by update_from_instance(); otherwise whatever it was saved with.

Method descriptions

copy_brushes()

func copy_brushes(map: HammeriteMap) -> HammeriteBrush[]

Deep copies of brushes with ids freshly drawn from map and prefab_id set. They stay in prefab-local space, carry no instance_id or layer, and are not added to the map.

copy_entities()

func copy_entities(map: HammeriteMap) -> HammeriteEntity[]

Deep copies of entities with ids freshly drawn from map and prefab_id set. Like copy_brushes(), they stay in prefab-local space and are not added to the map.

is_valid()

func is_valid() -> bool

Whether the prefab can be placed: a nonzero prefab_id, a non-empty prefab_name and at least one brush or entity.

generate_thumbnail()

func generate_thumbnail(generator: HammeriteThumbnailGenerator) -> bool

Generate or regenerate the preview thumbnail for this prefab. A coroutine: await it. Returns true if preview_texture was set, false when generator is null.

has_thumbnail()

func has_thumbnail() -> bool

Whether preview_texture is set.

update_from_instance()

func update_from_instance(instance: HammeritePrefabInstance, map: HammeriteMap) -> void

Update the prefab content from a live instance. Copies all brushes and entities from the instance, transforming them to be relative to the prefab origin. instance must be of this prefab (same prefab_id), or nothing changes and an error is printed. Emits prefab_updated. Only entity origins are moved into prefab space; an entity's own rotation property is copied as is.
