HammeriteBrushPropertyDef

Core: files, names and extension. Inherits RefCounted

One extendable property an addon has declared, on a brush or on the sky.

A def is the whole description of an authorable value: its key, its default, and enough of a hint for the editor to build the right control. It is NOT storage - the value lives sparsely in HammeriteBrush.properties, and a brush that has never been touched stores nothing at all and reads default straight off this def. Defs are created through HammeriteBrushPropertySchema.add(), never directly, so the key always carries its schema's namespace prefix (acoustic/zone_type) and two addons can never collide.

Property descriptions

key

var key: StringName = &""

Namespaced key, <schema id>/<name> - the key used in HammeriteBrush.properties.

label

var label: String = ""

Human-readable label for the editor row. Falls back to the un-namespaced name.

default

var default: Variant = null

Value used by every brush that has not overridden this property. Also decides the property's TYPE: the editor builds its control from typeof(default), so an int default with options set becomes a dropdown, a float becomes a spinbox, and so on.

options

var options: PackedStringArray = PackedStringArray()

Non-empty makes this an enum: the value is an int index into these names, drawn as a dropdown.

min_value

var min_value: float = -65536.0

Numeric bounds / granularity for int and float properties. Ignored for other types.

max_value

var max_value: float = 65536.0

The largest value the inspector offers. See min_value.

step

var step: float = 0.1

The granularity the inspector steps and snaps by. See min_value.

tooltip

var tooltip: String = ""

Tooltip shown on the property's label in the inspector.

short_name()

The un-namespaced name (the part after the schema prefix).

display_label()

func display_label() -> String

The label to show, falling back to the short name when none was given.

is_default()

func is_default(value) -> bool

True when value is this property's default, i.e. storing it on a brush would be redundant. Compared by value, so an int 0 and a float 0.0 are NOT the same default - a def's type is fixed by its default and the editor never produces the other one.
