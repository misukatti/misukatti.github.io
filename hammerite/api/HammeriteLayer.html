Hammerite 3D API reference

HammeriteLayer

Core: the map. Inherits Resource

A named, nestable group of brushes, entities and prefab instances that are shown, ghosted, hidden or locked together - and, optionally, a variant of the map.

Layers live in HammeriteMap.layers, and what is on one names it by its layer_id. The flags here are this layer's own setting; what a layer inside others actually is comes from the is_*_recursively methods. Layer 0 is the map's default layer and always exists. Make one with HammeriteMap.gen_layer() and add it with HammeriteMap.add_layer().

Property descriptions

id

var id: int = 0

Unique within the map, and what brushes, entities and instances name as their layer. 0 is the map's default layer. Set once, before HammeriteMap.add_layer(); nothing follows a change after that.

parent_id

var parent_id: int = 0

The layer this one sits inside, or 0 for the top level. Nothing here refuses a layer inside itself: ask HammeriteMap.is_layer_within() first. In a map, a change re-applies ghosting and can recompile the world, when it moves something into or out of a variant.

name

var name: String

Shown in the layer list, and how HammeriteMap.find_variant() finds a variant. Separate from Resource.resource_name, which get_name() here hides.

visible

var visible: bool = true

This layer's own visibility in the editor's views; whether it actually shows depends on the layers above it too (is_visible_recursively()).

ghosted

var ghosted: bool = false

Drawn see-through in the editor. Spreads to the layers inside it (is_ghosted_recursively()); HammeriteMap.apply_layer_ghosting() puts it onto the brushes, which a HammeriteMap3D showing the map does when this changes.

locked

var locked: bool = false

Whether the editor keeps this layer's contents from being edited. Spreads to the layers inside it (is_locked_recursively()). The map itself ignores it.

tint

var tint: Color = Color(1, 1, 1, 1)

The colour the editor's 2D views draw this layer's brushes in. Not inherited by the layers inside it.

variant

var variant: bool = false

Whether this layer is a variant of the map: what is on it, and on the layers inside it, exists only while it is the active variant or inside the one that is, and each variant is baked on its own.

is_locked_recursively()

func is_locked_recursively(map: HammeriteMap) -> bool

Whether this layer is locked, by its own setting or by sitting inside one that is. map is the map it is in, which is where its parents are looked up.

is_ghosted_recursively()

func is_ghosted_recursively(map: HammeriteMap) -> bool

Whether this layer is ghosted, by its own setting or by sitting inside one that is. The same shape as is_locked_recursively() and the opposite of is_visible_recursively(): ghosting and locking spread DOWN from a parent - a child of a ghosted layer is ghosted whatever it says about itself - while visibility needs every layer above it to agree.

is_visible_recursively()

func is_visible_recursively(map: HammeriteMap) -> bool

Whether this layer shows: it and every layer it sits inside are visible. map is the map it is in, which is where its parents are looked up.
