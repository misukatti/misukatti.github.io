HammeriteEditorHandle

Core: entities. Inherits RefCounted

One point in the world an author can take hold of and drag.

A vector property - which way a current runs, where a light is aimed, how far a door travels - is a direction and a distance, and typing six numbers at it is not how anybody knows whether it is right. A handle is the same value with something to grab. Offered by whatever owns the value, through the two optional hooks on the entity interface (get_editor_handles and move_editor_handle); the editor does the picking, the dragging and the snapping, and hands back a world position. What that position MEANS is the owner's - it is the one that knows the value is a direction rather than a point.

Property descriptions

id

var id: StringName = &""

Which handle this is, to the thing that offered it. Unique within one object; the editor never reads it.

position

var position: Vector3 = Vector3(0, 0, 0)

Where it is now, in world space.

color

var color: Color = Color(1, 1, 1, 1)

What colour it is drawn in. The editor lightens it while the cursor is on it.
