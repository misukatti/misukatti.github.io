Hammerite 3D API reference

HammeriteBrushEntity

Core: the map. Inherits Resource

An entity made of brushes rather than standing at a point: a door, a pool, a trigger volume.

Its brushes are ordinary HammeriteBrushes in HammeriteMap.brushes whose HammeriteBrush.brush_entity_id names it; they leave the carved world and are built by the entity's node instead. Give the entity an id and its HammeriteEntity.map first, then assign_brush() each brush, then HammeriteMap.add_entity(). An entity whose last brush goes deletes itself.

Method descriptions

add_brush()

func add_brush(brush: HammeriteBrush) -> void

Low level: append brush to the list without telling the brush or the map. Asserts it is not there already. Use assign_brush(), which calls this.

remove_brush()

func remove_brush(brush: HammeriteBrush) -> void

Low level: drop brush from the list without telling the brush; asserts it was there. The last brush going emits HammeriteEntity.delete_requested, which removes the entity from its map. Use unassign_brush(), which calls this.

get_brushes()

func get_brushes() -> HammeriteBrush[]

The brushes this entity owns. The entity's own array, not a copy: change it only through assign_brush() and unassign_brush().

assign_brush()

func assign_brush(brush: HammeriteBrush) -> void

Make this entity the owner of brush (HammeriteMap.assign_brush_to_entity()). The entity needs its HammeriteEntity.map and a non-zero id first; it need not be in the map yet.

unassign_brush()

func unassign_brush(brush: HammeriteBrush) -> void

Make brush belong to no entity again (HammeriteMap.unassign_brush_from_entity()); its tier is left as it is. Only takes it off this entity's list while the entity is in the map, where losing its last brush deletes it.

compute_origin()

func compute_origin() -> void

Set the origin property to the mean of the brushes' centroids, in map space. Nothing calls it for you: call it after the brushes change if anything reads this entity's origin.
