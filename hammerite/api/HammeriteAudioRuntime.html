HammeriteAudioRuntime

Audio. Inherits RefCounted

Process-wide access to the acoustic managers and the game's sound-type table.

The HammeriteAudio autoload is the friendly front door, but it cannot be the place this state lives. An autoload is only an identifier inside a running scene tree: a node that mentions one by name will not even compile in a headless tool script, which would put every node in this addon - and everything that tests them - out of reach of the test runner. So the registry is static, here, and the autoload delegates to it. Same lifetime, same single instance, no dependency on the scene tree existing.

Constants

What a map's sounds are called, as kinds of HammeriteReferences: a room's ambience, by id, and the recording in sounds that a sound entity plays.

SOUND_FILE

const SOUND_FILE = &"sound_file"

The HammeriteReferences kind a sound entity's sound_file is recorded under: a name in sounds.

Property descriptions

sound_types

var sound_types: HammeriteAudioSoundTypes = null

The game's sound types. Assigned once at startup; see HammeriteAudioSoundTypes. Assigning here reaches only managers registered afterwards: assign through the HammeriteAudio autoload, or call apply_sound_types(), to update the live ones too.

ambient_resolver

var ambient_resolver: Callable = Callable()

What an ambience id sounds like: called as resolver(id) and returning an AudioStream, or null for an id the game has no recording of. The id is the game's vocabulary, so the game answers it. With no resolver an id is taken as a name in sounds, the way an env_sound names its file.

sounds

var sounds: HammeriteAssetLibrary = <unknown>

Where a sound entity's or an emitter's sound_file becomes a recording (#87): a name such as doors/creak.ogg, found in the game's search paths or its own sources.

HammeriteAudioRuntime.sounds.search_paths = ["res://sounds"]

Empty until the game gives it a search path or a source: with neither, no sound resolves and every play reports No sound called ....

ambient_bus

var ambient_bus: StringName = &"Master"

The bus a room's ambience plays on. Not the Acoustic bus: a bed is already a recording of a space, and the room's reverb on top of it would be the room twice.

Method descriptions

register()

static func register(map_3d: HammeriteMap3D, manager: HammeriteAudioManager) -> void

Record the manager serving map_3d.

unregister()

static func unregister(map_3d: HammeriteMap3D) -> void

Forget the manager for map_3d.

for_node()

static func for_node(context: Node = null) -> HammeriteAudioManager

The manager that applies to context, or null if there is none yet. Resolved by walking up to the HammeriteMap3D the node lives under, since a node inside a map belongs to that map's acoustics. A node outside any map - a player parented to the scene root, which is the normal arrangement - falls back to the only manager there is, and says so rather than guessing when there are several.

looped()

static func looped(stream: AudioStream, loop: bool) -> AudioStream

stream, looping or not as loop says, whatever it was imported as. A copy whenever that differs from the resource, never the resource itself: one loaded stream is shared by everything that plays that file, and making it loop for a rain loop made every one-shot of it loop too. And a WAV loop is given its end - switched on with its loop end left at zero, as import settings leave it, a WAV plays nothing at all.

register_entity_types()

static func register_entity_types() -> void

Declare env_sound and env_sound_environment, unless something already has: a game that refined one with HammeriteEntityTypeRegistry.extend_point() keeps what it added. From the autoload, so a game knows them before it builds a map, with or without the editor.

declare_references()

static func declare_references() -> void

Say which of this addon's properties name sounds, so a map records the ones it uses (#86).

ambient_stream()

static func ambient_stream(id: String) -> AudioStream

The recording for ambience id, through ambient_resolver.

apply_sound_types()

static func apply_sound_types() -> void

Push the sound-type table to every live manager. Called when the table is assigned.

clear()

static func clear() -> void

Forget every manager and the sound-type table. Test support; sounds, ambient_resolver and ambient_bus are left as they are.
