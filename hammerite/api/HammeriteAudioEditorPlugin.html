HammeriteAudioEditorPlugin

Audio. Inherits RefCounted

Acoustic System Editor Plugin.

Adds acoustic entity types and a toolbar button/tool to the Hammerite HammeriteMapEditor. Requires hammerite-editor. Zones and portals are no longer authored: they are derived from the compiled world. The tool this plugin adds inspects that derived graph and names the openings in it, which is the only part of a portal an author still decides. The runtime side (HammeriteAudioManager injection into HammeriteMap3D) is handled separately and unconditionally by the HammeriteAudio autoload, so acoustic propagation works whether or not this editor plugin is ever initialized -- see scripts/hammerite_audio.gd. Initialize it after integrating the HammeriteMapEditor:

var acoustic_editor_plugin := HammeriteAudioEditorPlugin.new()
acoustic_editor_plugin.initialize(map_editor)

Method descriptions

initialize()

func initialize(editor: HammeriteMapEditor) -> void

Initialize the plugin with a HammeriteMapEditor instance: registers env_sound and env_sound_environment, the Acoustics floorplan overlay, the toolbar button and menu command, and the manual section. Call once per editor.

cleanup()

func cleanup() -> void

Clean up when the plugin is removed: the overlay, menu command, manual section and toolbar button. The entity types it registered stay registered.

init_acoustic_portal_tool()

func init_acoustic_portal_tool() -> void

Activate the acoustic portal tool (inspect the derived graph, name its openings).
