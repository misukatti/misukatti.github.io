HammeriteDynamicDirectionalLight3D

Core: entities. Inherits HammeritePointEntityNode3D < Node3D

A baked directional light that can be switched at run time (entity type light_directional_dynamic): lightning, say, or a sun that sets.

Baked into a light slot and switched by modulating it, as HammeriteDynamicPointLight3D is, and likewise only triggerable when its entity has a non-empty name. Unlike that class it re-applies its modulation every frame while simulating, has no get_lit_modulation() to override, and is never culled with the rooms out of view.
