HammeritePointEntityRigidBody3D

Core: entities. Inherits RigidBody3D

A point entity the PHYSICS decides where to put: a crate, a bottle, anything that can be knocked over, picked up or thrown.

Same interface as HammeritePointEntityNode3D, on a body that falls. Reach for it when where the thing ends up is not something the map can say - HammeritePointEntityAnimatableBody3D is for what is driven from script, and HammeritePointEntityNode3D for what only needs to be somewhere. It starts asleep where it was authored. A physics body placed in a map and left running settles, drifts and ends up somewhere nobody put it - in the editor, where an author is still looking at it, and in the seconds after a level loads. Asleep it stays exactly where it was placed, and the first thing to touch it wakes it, which is the moment the physics starts being worth having. What it costs is that a prop authored in mid-air hangs there until something disturbs it.

place_at()

func place_at(where: Transform3D) -> void

Put it somewhere and let it rest there, whatever the physics was in the middle of. The one way to move one of these from script. Anything that assigns to global_transform is writing to a value the physics server owns and will overwrite, which is a body that does not move and a bug that looks like the caller being ignored.

update_properties()

func update_properties() -> void

As HammeritePointEntityNode3D.update_properties(), except that scale is not applied, and rotation only once the body is in the tree.

request_rebuild()

draw_editor_gizmos()

func draw_editor_gizmos(_gizmos: HammeriteGizmoBuffer) -> void

Draw what the author should see of this entity - its bounds, where it points, how far it reaches - into gizmos. The editor calls it every frame it is up and the entity is visible; the default draws nothing.

get_editor_handles()

func get_editor_handles() -> HammeriteEditorHandle[]

The points of this entity an author may take hold of in the viewport, or nothing where it offers none. Drawn and picked by the editor while the entity is selected; see HammeriteEditorHandle.

move_editor_handle()

func move_editor_handle(_handle_id: StringName, _to: Vector3) -> void

get_actions()

func get_actions() -> Dictionary[StringName, String]

The actions this entity offers in the editor's runtime panel, as id -> label. Every entity that says it can be triggered gets Trigger for nothing. Override to add more, and call super() unless you mean to drop it.

run_action()

func run_action(action_id: StringName) -> void

Do one of get_actions(). Override alongside it.

apply_entity_property()

abstract func apply_entity_property(prop_name: StringName, value) -> void

As HammeritePointEntityNode3D.apply_entity_property(). rotation has been applied through place_at() before this is told, if the body is in the tree; scale never is. Move the body with place_at() here too, not by assigning its transform.
