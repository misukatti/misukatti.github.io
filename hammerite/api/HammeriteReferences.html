HammeriteReferences

Core: files, names and extension. Inherits RefCounted

What a map names that lives outside it - a texture, a model, a sound, a scene somebody plays out - and who provided each one when the map was saved (#86).

A property says it names a thing of some KIND (declare_entity_property() and its brush and face twins). Hammerite knows a few kinds of its own and nothing of what the rest mean: the game answers who provides a name through set_resolver(), and a kind nobody answers for counts as the game's own (BASE). record() writes the answers into HammeriteMap.references when the map is saved, and check() asks again after it is loaded. What changed in between is reported, never acted on: whether a missing sound is a warning or a reason to refuse the map is the game's call.

Method descriptions

declare_entity_property()

static func declare_entity_property(entity_type: StringName, property: StringName, kind: StringName, list: bool = false) -> void

Say that property of an entity of entity_type - every type, when empty - names a thing of kind. A list holds several names, separated by commas or spaces.

declare_brush_property()

static func declare_brush_property(key: StringName, kind: StringName, list: bool = false) -> void

Say that brush property key (a HammeriteBrushPropertySchema key) names a thing of kind on every brush. list as in declare_entity_property().

declare_face_property()

static func declare_face_property(key: StringName, kind: StringName, list: bool = false) -> void

Say that key in HammeriteFace.properties names a thing of kind on every face. list as in declare_entity_property().

set_resolver()

static func set_resolver(kind: StringName, resolver: Callable) -> void

Who provides a name of kind: resolver takes the name and returns {"provider": id, "version": v} - or true for the game's own, or null when nothing does. Replaces Hammerite's own answer for its kinds, which only knows whether the game has the thing at all.

reset_resolvers()

static func reset_resolvers() -> void

Forget every resolver the game set, leaving Hammerite's own.

resolve()

static func resolve(kind: StringName, name: String) -> Variant

Who provides name now, as {"provider", "version"}, or null when nothing does.

collect()

static func collect(map: HammeriteMap) -> Dictionary[StringName, PackedStringArray]

Every name map uses, by kind, each once and in order.

record()

static func record(map: HammeriteMap) -> void

Write down who provides everything map uses, as it is now, into HammeriteMap.references. What the editor does on save; HammeriteDataFile.write() does not.

check()

static func check(map: HammeriteMap) -> HammeriteReferenceChange[]

What is different about what map uses since it was saved: a name nothing provides any more, one someone else provides now, or one whose provider has a new version. A map saved before any of this was recorded is still checked for what is missing.
