Hammerite 3D API reference

Hammerite API reference

Every class on this list is supported: from 1.0 only a major release removes or changes what is documented here. Anything else in the addons is experimental and may change in any release - see API stability. This reference is generated from the documentation comments in the source; Godot's built-in help (F1 in the Godot editor) shows the same text.

Core: the map

Class
HammeriteMapA level as authored: brushes, entities, layers and prefab instances, with the lighting baked for it and the world compiled from it.
HammeriteBrushA convex volume bounded by HammeriteFace planes: the unit a HammeriteMap is authored in.
HammeriteFaceOne bounding plane of a HammeriteBrush, and what its surface looks like.
HammeriteEntityOne placed thing in a HammeriteMap that is not world geometry: a light, a prop, a spawn point.
HammeriteBrushEntityAn entity made of brushes rather than standing at a point: a door, a pool, a trigger volume.
HammeriteLayerA named, nestable group of brushes, entities and prefab instances that are shown, ghosted, hidden or locked together - and, optionally, a variant of the map.
HammeriteCellOne convex piece of carved air, derived by the compiler; rooms are groups of these.
HammeritePortalA derived portal joining two air HammeriteCells in the subtractive world model.
HammeriteBoundaryWallA cell-wall face after portal apertures have been punched out of it.
HammeritePrefabA prefab containing brushes and entities.
HammeritePrefabSetA collection of prefabs.
HammeritePrefabInstanceA prefab instance in the map.
HammeriteSkyboxWhat is outside a map: a scale model of the world beyond it, and the sky over that.

Core: in the scene

Class
HammeriteMap3D3D representation of a HammeriteMap.
HammeriteWorldrepCompileA just-loaded map's worldrep, compiled on a worker thread so that whoever loaded it can go on drawing, say how far the compile has got, and let it be cancelled (#109).
HammeriteCompileProgressHow far a worldrep compile has got, and whether it has been asked to stop.

Core: entities

Class
HammeritePointEntityNode3DBase for the node of an entity that stands at one point: a light, a marker, a pickup.
HammeritePointEntityAnimatableBody3DA point entity that MOVES and that the world can collide with: a door leaf, a lift, a drawbridge.
HammeritePointEntityRigidBody3DA point entity the PHYSICS decides where to put: a crate, a bottle, anything that can be knocked over, picked up or thrown.
HammeriteBrushEntityNode3DBase for the node of an entity made of brushes: a door, a volume of water, a trigger.
HammeriteBrushEntityStaticBody3DThe interface of HammeriteBrushEntityNode3D on a StaticBody3D: brushwork that is solid, such as a door leaf.
HammeriteBrushEntityArea3DThe interface of HammeriteBrushEntityNode3D on an Area3D: brushwork that notices what is inside it, such as water or a trigger.
HammeritePointLight3DA baked point light (entity type light_point): a lamp that is part of the bake and cannot be switched.
HammeriteDynamicPointLight3DA baked point light that can be switched and dimmed at run time (entity type light_point_dynamic).
HammeriteDirectionalLight3DA baked directional light (entity type light_directional): sun or moonlight, entering through the map's sky faces.
HammeriteDynamicDirectionalLight3DA baked directional light that can be switched at run time (entity type light_directional_dynamic): lightning, say, or a sun that sets.
HammeriteGenericBrushEntityA minimal, concrete brush entity implementation.
HammeritePropModelA model placed in a map (entity type prop_model): a crate, a statue, a barrel.
HammeriteDecal3DA picture stuck on a wall: a scorch mark, a poster, a bloodstain.
HammeriteGizmoBufferWhat the editor is asked to draw over the level for one frame: the shape a tool is dragging out, a selection's wireframe, a marker on the cursor.
HammeriteEditorHandleOne point in the world an author can take hold of and drag.

Core: lighting

Class
HammeriteLightmapperGPU-accelerated lightmap baker for Hammerite brush/BSP levels.
HammeriteBakedLightThe runtime handle of one light slot a bake wrote into the lightmaps and probes.
HammeriteLightProbeSetA map's baked light probes, with a uniform spatial grid for finding the nearest ones.
HammeriteLightCurveWhat a measured light level is worth to the eye, as a gain over the level itself.
HammeriteLightmapSampler3DEye adaptation: what the player is standing in decides how bright the screen is.
HammeriteBakeOccludersProcess-wide registry of things that STOP light without ever being lit.
HammeriteBakeOccluderOne lump of matter that stops light in a bake and is never lit by it.
HammeriteBrushEntityLightingThe handover for brushwork that is baked into the world and then moves.
HammeriteShaderGlobalsThe global shader uniforms Hammerite's materials read.

Core: files, names and extension

Class
HammeriteDataFileSaves and loads a map - or any resource made of Hammerite's own - as data that cannot run code, at any path on disk (#85).
HammeriteUnknownDataAn object of a class this game does not have, carried through a data file unread (#124).
HammeriteReferencesWhat a map names that lives outside it - a texture, a model, a sound, a scene somebody plays out - and who provided each one when the map was saved (#86).
HammeriteTextureLibraryWhere a texture NAME becomes a texture.
HammeriteModelLibraryWhere a prop's model name becomes a mesh (#87).
HammeriteAssetLibraryWhere a NAME becomes a model, a sound - a resource of one kind (#87).
HammeriteBrushPropertySchemaA named group of extendable brush properties contributed by an addon.
HammeriteBrushPropertyDefOne extendable property an addon has declared, on a brush or on the sky.
HammeriteBrushPropertyRegistryProcess-wide registry of the extendable brush property schemas addons have contributed.
HammeriteBrushFillRegistryProcess-wide registry of the fills an air brush can be filled with, and the classes a game wants instantiated over them.
HammeriteSkyPropertySchemaA set of properties a game or an addon adds to the sky (see HammeriteSkyPropertyRegistry): weather, a haze, whatever it draws under a sky that Hammerite has no opinion about.
HammeriteSkyPropertyRegistryThe properties games and addons have added to the sky: the seam through which a game puts its own weather on a map's sky without Hammerite knowing what weather is.
HammeriteUtilsSmall node helpers shared across the Hammerite addons.
HammeriteVersionWhich Hammerite this is.

Editor

Class
HammeriteMapEditorThe in-game level editor: a Control that edits a HammeriteMap through the game's own HammeriteMap3D, and the object games and addons extend it through.
HammeriteMapEditorSettingsThe project's starting configuration for HammeriteMapEditor: its palette, its starting UI scale, and the defaults of the options an author can toggle.
HammeriteEditorColorsEvery colour the editor draws the WORLD in: the viewports, the overlays, the gizmos (#48).
HammeriteEditorThemeWhat the editor looks like: one Theme every control in it inherits.
HammeriteEditorCommandOne thing the editor can be asked to do, and how it is asked.
HammeriteEditorCommandsEvery command the editor has, what it is bound to, and where it appears.
HammeriteEditorToolBase class for an editor tool: the one thing the author's clicks and keys go to in the viewports.
HammeritePropertyControlOne property's editing control, as the property panel expects to find it.
HammeriteEditorWorkspacesThe level editor as one workspace among several, and a tab strip to change between them.
HammeriteManualThe manual: its sections, their pages, links between them and search over all of it.
HammeriteNotableSizesThe measurements a game finds worth naming, so a dimension being dragged can say what it is.

Audio

Class
HammeriteAudioRuntimeProcess-wide access to the acoustic managers and the game's sound-type table.
HammeriteAudioManagerOne map's sound: plays sounds through its acoustic graph, sets the reverb, and tells listeners.
HammeriteAudioEmitter3DA thing in the world that makes a sound, as a node.
HammeriteAudioListener3DSomething in the world that can hear, as a node.
HammeriteAudioSoundTypesThe game's table of HammeriteAudioSoundTypes, assigned to HammeriteAudio.sound_types.
HammeriteAudioSoundEventOne sound, as heard by one listener.
HammeriteAudioPresetAcoustic Preset - Pre-configured Acoustic Environment
HammeriteAudioMaterialDBDatabase of acoustic materials and texture-to-material mapping
HammeriteAudioBrushPropertiesThe acoustic character of a room, authored on the air brush that carves it.
HammeriteAudioPortalPropertiesAuthored acoustic values on a portal, stored on the face the aperture is punched from.
HammeriteAudioEditorPluginAcoustic System Editor Plugin.

Navigation

Class
HammeriteNavigationRuntimeProcess-wide navigation state, and the one route by which a bake happens.
HammeriteNavigationAgentProfileOne kind of thing that moves, as far as navigation is concerned: how big it is and what it can haul itself up, drop off or jump across.
HammeriteNavigationAgentProfilesThe game's table of HammeriteNavigationAgentProfiles, handed to the bake.
HammeriteNavigationBrushPropertiesWhat a room costs to cross, authored on the air brush that carves it.
HammeriteNavigationEditorPluginAdds the navigation tool to a Hammerite HammeriteMapEditor.
HammeriteNavigationLink3DThe 3D presence of an authored navigation link: a ladder, a rope, a drainpipe.
HammeriteNavigationBakeReportWhat one navigation bake did, and what it could not do.
HammeriteNavigationSurfaceOne convex patch of ground an agent could stand on, and what is measured about it.
HammeriteNavigationLinkDataA way from one patch of ground to another that is not walking: a window climbed through, a ledge dropped off, a gap jumped, a ladder someone placed.
HammeriteNavigationBuilderDerives the walkable ground of a compiled map.
HammeriteNavigationLinkBuilderFinds the ways through a level that are not walking, and measures them.
HammeriteNavigationMeshEmitterTurns measured ground into Godot navigation meshes, one per room.
