HammeriteNavigationLinkBuilder

Navigation. Inherits RefCounted

Finds the ways through a level that are not walking, and measures them.

Why there are any. Ground derived from a carved world already connects itself: two rooms that abut are joined by an aperture the compiler punched from their shared wall, and their floors come out coplanar and edge-coincident, so the navigation server stitches the two regions together and an agent walks from one to the other without anything being authored. Measured on two_windows, every ordinary doorway in the level connects for free. What does NOT connect is a height discontinuity. A window with a 96-unit sill, a balcony over a hall, a gap between two roofs - the ground stops, and the ground on the other side is somewhere else. Those are the links, and they are exactly the places a stealth game cares about, because they are the routes a guard cannot take and a thief can. Three are derived and one is authored. Windows come from apertures whose sill stands above the floor; drops from a patch of ground overhanging lower ground; jumps from two patches within reach of each other across clear air. What cannot be seen in the geometry - that this ladder is climbable, that this rope reaches the balcony - is placed by hand as a ENTITY_TYPE entity. Nothing here knows what an agent is. Every link carries how high it must be climbed, how far it spans, how far it falls and how wide and tall the way through is; agent profiles compare against those numbers game-side. The thresholds below are only about what is worth LOOKING at - generous enough that nothing a game might permit is missed.

Constants

SILL_EPSILON

const SILL_EPSILON = 1.0

Ground this much above an aperture's sill is level with it, and the opening is a doorway rather than a window. Small on purpose: a step of any real size does not connect for free, so it is a link, and the threshold only has to clear the noise in coincident floor planes.

MIN_LINK_HEIGHT

const MIN_LINK_HEIGHT = 0.5

Below this, two patches of ground are the same ground: their polygons are coplanar, the emitter stitches them, and an agent walks between them without anything being emitted. Above it the navigation server joins nothing, so something has to cross the gap however small it is.

MAX_STEP_HEIGHT

const MAX_STEP_HEIGHT = 18.0

The tallest rise that is a STEP rather than a drop or a climb - one stair tread, one kerb. 18 units, which is the step height this project inherits from Hammer and which its stairs are built to. It is a fact about the world's units rather than about any particular creature, which is why it lives here; whether a given agent can manage one is its profile's business (HammeriteNavigationAgentProfile.climb_height), so a rat with an 8-unit stride still cannot use a staircase built for people.

MAX_DROP

const MAX_DROP = 1024.0

Drops further than this are not looked for. Nothing walks off a 1024-unit cliff on purpose, and the pair would only be filtered out game-side anyway.

MAX_JUMP_SPAN

const MAX_JUMP_SPAN = 128.0

The widest gap treated as jumpable, and the biggest height change across one. Deliberately larger than any agent's real reach: what is generated is a candidate, and profiles do the rejecting.

MAX_JUMP_RISE

const MAX_JUMP_RISE = 96.0

The biggest height change across a jump looked for, either way, in map units.

EDGE_PROBE

const EDGE_PROBE = 8.0

How far past a patch's edge to look for what is below it. Far enough to clear the edge, near enough to still be over the drop rather than over the next room.

ENDPOINT_INSET

const ENDPOINT_INSET = 24.0

How far into each room a window's endpoints are placed, measured from the opening. Somewhere an agent can actually stand, rather than in the plane of the wall.

AIR_PROBE_HEIGHT

const AIR_PROBE_HEIGHT = 4.0

Height above the ground that clear-air checks are run at, so a segment that grazes the floor it starts on is not read as blocked.

EDGE_INSET

const EDGE_INSET = 4.0

How far inside its own patch a link's endpoint is pulled from the edge it was found on. Not cosmetic. The nearest point between two patches is often a CORNER, and a patch's corner sits in the wall the room ends at - which is in neither cell, so the clear-air check between two such points reads as blocked and a jump anyone can see would silently not be generated. A step inside puts both ends in the room they belong to.

GAP_SAMPLES

const GAP_SAMPLES = 3

How many points along a candidate gap are checked for ground before it is believed to be a gap.

HEIGHT_EPSILON

const HEIGHT_EPSILON = 0.5

Two heights within this are the same height.

BUCKET_SIZE

const BUCKET_SIZE = 64.0

Plan-grid bucket size for the surface index. A lookup scans every patch in its bucket at every height, and the gap check makes three for each pair of patches within a jump of one another: at 256 - core's cell hash - the reference level's floors stacked deep enough in each bucket that those lookups were more than half of building its links.

ENTITY_TYPE

const ENTITY_TYPE = &"nav_link"

Entity type of an authored link, and the properties it carries.

TARGET_KEY

const TARGET_KEY = &"nav_link_target"

Entity property: a Vector3 from the entity's origin to the link's far end, in map units. A link whose far end is less than a unit away is dropped with a warning. Any entity carrying this is read as a link, whatever its type.

NAME_KEY

const NAME_KEY = &"nav_link_name"

Entity property: the link's name, for HammeriteNavigationRuntime.set_link_enabled().

ONE_WAY_KEY

const ONE_WAY_KEY = &"nav_link_one_way"

Entity property: true lets the link be taken only from the entity towards its far end.

SMALL_GROUND_BUCKET

const SMALL_GROUND_BUCKET = 16.0

Plan bucket size, in map units, for indexing patches no wider than SMALL_GROUND_SPAN.

LARGE_GROUND_BUCKET

const LARGE_GROUND_BUCKET = 64.0

Plan bucket size, in map units, for indexing the larger patches.

SMALL_GROUND_SPAN

const SMALL_GROUND_SPAN = 128.0

Largest a surface may be across, in plan, to go in the fine buckets.

ALONG_EDGE

const ALONG_EDGE = Array[float]([0.5, 0.25, 0.75, 0.125, 0.875])

The middle of an edge, then either side of it.

ALONG_SHORT_EDGE

const ALONG_SHORT_EDGE = Array[float]([0.5])

Where along an edge shorter than LONG_EDGE a drop is looked for: its middle only.

LONG_EDGE

const LONG_EDGE = 64.0

The shortest edge asked anywhere but at its middle: its places are then EDGE_PROBE apart.

NATIVE_NAV_LINKS

const NATIVE_NAV_LINKS = &"HammeriteNativeNavLinks"

Class name of the native kernel native_jumps looks for.

NATIVE_JUMP_CHUNK

const NATIVE_JUMP_CHUNK = 512

How many surfaces the kernel is handed at a time, so the bake still says how far it has got and can be stopped.

Property descriptions

warnings

var warnings: String[] = []

What the last build could not do: an authored link with no other end, a window nobody can reach.

progress

var progress: HammeriteCompileProgress = null

Told how far build_links() has got, when it runs as part of a compile. It stops early once this says it was cancelled.

native_jumps

var native_jumps: bool = <unknown>

Whether jumps are found by the native kernel (#116), which finds exactly the pairs worth asking about that the loop in _jump_links() does, in the same order, and where each would leave and land. Asked of a million pairs, that loop was more than half of building a level's navigation. The suites turn it off to check one against the other.

Method descriptions

build_links()

func build_links(map: HammeriteMap, surfaces: HammeriteNavigationSurface[]) -> HammeriteNavigationLinkData[]

Every traversal link in map, derived from surfaces (the output of HammeriteNavigationBuilder) and from what the author placed.
