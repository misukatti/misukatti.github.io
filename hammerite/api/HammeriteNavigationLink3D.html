HammeriteNavigationLink3D

Navigation. Inherits HammeritePointEntityNode3D < Node3D

The 3D presence of an authored navigation link: a ladder, a rope, a drainpipe.

An authored link is the one kind of route with nothing to look at. The others are derived from geometry that is already on screen - a window is a hole you can see - but this one asserts that a way exists where the world shows none, so unless it draws itself there is nothing to aim, nothing to notice you got backwards, and nothing to click. Authoring one never goes near the nav tool: it is placed with the entity tool from the entity picker, and its far end, name and one-wayness are typed into the ordinary property panel. So the drawing lives here, where the authoring is. HammeriteNavigationTool remains the view of the whole network - every link the level has, coloured by kind - and this is the one in your hand.

Constants

LINK_COLOR

const LINK_COLOR = Color(0.3, 1, 0.85, 1)

Matches HammeriteNavigationTool's colour for an AUTHORED link, so the same link reads the same whether that tool is open or not. Copied rather than shared: the tool is an editor class, and this has to exist in a build that ships without the editor.

BROKEN_COLOR

const BROKEN_COLOR = Color(1, 0.35, 0.3, 1)

A link whose far end is its near end. HammeriteNavigationLinkBuilder drops these with a warning, so say so while it can still be fixed rather than at bake time.

LIFT

const LIFT = Vector3(0, 2, 0)

Clear of the floor, so a link running along the ground is not lost in it. The lift the nav tool draws with, for the same reason.

HEAD_LENGTH

const HEAD_LENGTH = 12.0

Length of an arrowhead stroke, in map units.

HEAD_SPREAD

const HEAD_SPREAD = 0.45

How far an arrowhead's strokes splay, as a share of HEAD_LENGTH.
