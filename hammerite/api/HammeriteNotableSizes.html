HammeriteNotableSizes

Editor. Inherits RefCounted

The measurements a game finds worth naming, so a dimension being dragged can say what it is.

An author sizing a doorway is really asking "will someone fit through this", and the answer is a number they have to remember. A measurement that says 108 (door height) answers it while the drag is still happening. Hammerite registers nothing itself: what is notable is a fact about a game - how tall its people are, how high it hangs its doors - and a level editor that guessed would be wrong for every game but one. A game registers its own from the constants it already has:

HammeriteNotableSizes.register(72.0, "player height")
HammeriteNotableSizes.register(18.0, "step")

Editor-only, unlike the brush property and fill registries: this exists to be read while dragging, and a shipped game with no editor in it never asks.

Constants

TOLERANCE

const TOLERANCE = 0.5

How far off a measurement may be and still be that thing, in units. It equals the rounding name_for() already does, so it never rejects anything on its own: a measurement takes the name of the whole-unit size it rounds to.

Method descriptions

register()

static func register(units: float, label: String) -> void

Name units label. The size is kept rounded to a whole unit and without its sign, so 7.5 and 8 are one entry. Registering the same size again replaces the name, so a game re-initializing does not have to care whether it has run before - and so two things that happen to be the same size are one name, which the game should say in the name ("wall / hallway height") rather than leaving the viewport to pick one.

unregister()

static func unregister(units: float) -> void

Forget the name for units, if it has one.

clear()

static func clear() -> void

Forget every name. Test support; a game registers once.

name_for()

static func name_for(units: float) -> String

What units is called, or "" when it is not a size anything named. Sign is ignored: 72 units of anything is a player's height whichever way it was dragged.

get_sizes()

static func get_sizes() -> int[]

Every named size, smallest first, for anything that wants to show the table.
