Signals

entity_instance_created

signal entity_instance_created(entity: HammeriteEntity, instance: Node)

Emitted when an entity instance is created

entity_instance_removed

signal entity_instance_removed(entity: HammeriteEntity, instance: Node)

Emitted when an entity instance is about to be removed

custom_data_changed

signal custom_data_changed(key: StringName, value)

Emitted by set_custom_data(). Writing custom_data directly emits nothing.

map_changed

signal map_changed(map: HammeriteMap)

Emitted after map is set to a new value (including null). Lets extensions (e.g. hammerite-audio) react to map changes without depending on HammeriteMapEditor.

map_assigned

signal map_assigned(map: HammeriteMap)

Emitted when a map has been assigned but BEFORE its contents are built. For the systems a map's own contents depend on. Acoustics is the example: the entities built by _init_map include sounds, and a sound asks for its acoustic manager the moment it is created - so a manager set up on map_changed arrives too late, and the sound binds to the outgoing map's manager or to none at all. Anything that a map's entities will reach for during construction has to be standing before construction starts.

simulation_reset

signal simulation_reset()

Emitted after every entity has been told to reset_simulation(). For what a game keeps outside its entities - what has happened, what the player is carrying - which no entity can put back, but a playtest changed all the same.

Constants

NEAR_PLANE

const NEAR_PLANE = 1.0

What a camera looking at a Hammerite map should see, in Hammerite units (see the Units table in the README): a unit is about an inch, and rooms are hundreds of units across. Godot's own defaults are metres - 0.05 to 4000 - so a map measured in inches is cut off at a hundred yards and spends most of its depth precision on the first inch. A long sightline loses its far end, which shows up first on water: a flat sheet meets the far plane along a straight line, where a wall just stops. A game sets these on its own camera; HammeriteEditorCamera3D sets them on the editor's.

FAR_PLANE

const FAR_PLANE = 65536.0

The far plane to pair with NEAR_PLANE, in Hammerite units.

PROP_ROOM_STEP

const PROP_ROOM_STEP = 96.0

How far apart a prop's box is asked which room it is in along its longest side, in units: a pipe runs through rooms its ends are not in.

PROP_ROOM_STEPS

const PROP_ROOM_STEPS = 16

And at how many places along it at the most.

MOST_SURFACES

const MOST_SURFACES = 256

The most surfaces a mesh may have (the engine's RenderingServer.MAX_MESH_SURFACES).

Property descriptions

map

var map: HammeriteMap = null

The map this node shows. Assigning one frees everything built for the previous map and builds the new one at once, whether or not this node is in a tree yet; map_assigned fires before the build and map_changed after it.

editor_active

var editor_active: bool = false

Whether the editor is on screen, and so whether entity instances should draw what they draw for the author: a light's billboard, a marker for something with no mesh of its own. Off by default, because a game that ships without hammerite-editor should never show them. hammerite-editor keeps this in step with itself; nothing else has to touch it. Held here rather than subscribed to from here, so an entity created while it is already on can be told so as it is built - see create_entity_instance() - instead of waiting for the next change and drawing nothing until then.

editor_camera

var editor_camera: Camera3D = null

The camera the rooms are culled for while editor_active - the editor's own, which is not the viewport's. None, and the editor shows every room.

custom_data

var custom_data: Dictionary[StringName, Variant] = {}

Generic storage for runtime data (similar to HammeriteMap.custom_data) Plugins and systems can store their data here using unique keys

wireframes_visible

var wireframes_visible: bool = true

Whether the authoring overlays are drawn while the editor is up: the air brushes' wireframes, and the tint marking detail-tier brushwork. Both are an author's affordance rather than part of the world, and both are the host's to switch - see set_wireframes_visible() and set_detail_tint_visible().

detail_tint_visible

var detail_tint_visible: bool = true

Whether detail-tier brushwork is tinted while the editor is up. Change it through set_detail_tint_visible(): assigning it directly redraws nothing.

use_native_rooms

var use_native_rooms: bool = true

Whether _walls_by_room() asks the native kernel (HammeriteMap.native_rooms_facing()). Settable, so a suite can build both ways.

Method descriptions

set_map()

func set_map(_map: HammeriteMap) -> void

Setter of map. Does nothing when _map is already the map.

set_editor_active()

func set_editor_active(active: bool) -> void

Setter of editor_active: tells every entity instance and air-brush preview. Turning it off also rebuilds the rooms' collider if an edit left it stale.

set_wireframes_visible()

func set_wireframes_visible(visible_now: bool) -> void

Show or hide the air brushes' wireframes, for a host that gives an author the choice.

set_detail_tint_visible()

func set_detail_tint_visible(visible_now: bool) -> void

Show or hide the tint that marks detail-tier brushwork (HammeriteStaticBrush3D).

set_custom_data()

func set_custom_data(key: StringName, value) -> void

Store value in custom_data under key and emit custom_data_changed.

start_simulation()

func start_simulation(entities: HammeriteEntity[] = []) -> void

Start or continue simulating entities. Affects only a subset if an array of entities is passed as an argument.

stop_simulation()

func stop_simulation(entities: HammeriteEntity[] = []) -> void

Pause entities that can simulate, leaving them as they are. An empty entities means every entity in the map.

reset_simulation()

func reset_simulation(entities: HammeriteEntity[] = []) -> void

Put entities back as the map built them, including those that say they cannot simulate, and emit simulation_reset. An empty entities means every entity in the map.

is_authoring()

func is_authoring() -> bool

Whether the world is held still for an author: the editor is active and nothing in it has been started. False in a game with no editor, whose world is always running.

is_simulating()

func is_simulating(entity: HammeriteEntity) -> bool

Whether entity has been told to start and not yet told to stop.

has_simulated()

func has_simulated(entity: HammeriteEntity) -> bool

Whether entity has run since the last reset. True while it is paused, unlike is_simulating(); false once it has been reset.

can_simulate()

func can_simulate(entity: HammeriteEntity) -> bool

Whether entity has a running instance that says it can be simulated at all. A light can; a marker with nothing to do cannot, and neither can an entity the map has not built yet.

clear_map()

func clear_map() -> void

Free everything built from map - brushes, entities, fills, rooms, colliders - and clean up the "acoustic_manager" in custom_data. map stays assigned and its signals stay connected, so a brush or entity added to it afterwards is built again; assign null to map to let go of a map instead.

get_brush_instance()

func get_brush_instance(brush: HammeriteBrush) -> Variant

The node drawing brush on its own - a HammeriteStaticBrush3D for a detail brush - or null for a structural or air brush, which the compiled rooms draw, and for a brush owned by an entity.

create_brush_instance()

func create_brush_instance(brush: HammeriteBrush) -> void

Build what brush needs here: its fill's node, silt in water, a wireframe preview for an air or temporary brush, or a HammeriteStaticBrush3D for a detail one. Called for every brush the map has or gains; asserts if the brush already has a detail instance.

get_fill_instance()

func get_fill_instance(brush: HammeriteBrush) -> Node

The game's node over brush's fill, or null when it has no fill or nothing registered a class for it.

get_fill_instances()

func get_fill_instances() -> Node[]

Every node a fill has put over a brush, for whoever has to ask all of them something - the editor asking what to draw, and what an author may take hold of.

remove_brush_instance()

func remove_brush_instance(brush: HammeriteBrush) -> void

Finds the 3D representation of a brush and removes it from the tree.

rebuild_brush_instance()

func rebuild_brush_instance(brush: HammeriteBrush) -> void

remove_brush_instance() then create_brush_instance().

prop_reshaped()

func prop_reshaped(prop: HammeritePropModel) -> void

prop has moved, turned, grown or been given another model: the rooms it stands in are asked again, its alone. An author dressing a level moves props one at a time among thousands.

rooms_of_box()

func rooms_of_box(box: AABB) -> Dictionary[Vector2i, bool]

The rooms box reaches into, by HammeriteCell.key(): those its middle, its corners and places along its longest side are in.

is_room_seen_at()

func is_room_seen_at(point: Vector3) -> bool

Whether the camera can see into the room point is in, through the doorways from the room it stands in - as _cull_rooms() last worked it out for drawing, and as conservative: true for a room it cannot rule out. True as well where nothing is being ruled out - with the camera in no room - and for a point in no room. For a game deciding what is worth doing every frame: somebody in a room that is not drawn is not seen.

is_light_seen()

func is_light_seen(light: HammeriteEntity) -> bool

Whether the camera can see into any room light's baked light falls in - not only the one it stands in: a lamp lights the wall across a doorway from it. As conservative as is_room_seen_at(), and true wherever that is, as with the camera in no room. True as well for a light no bake holds, which has nothing to say either way. For a light deciding whether its flicker is worth telling anyone this frame.

piece_uv2()

func piece_uv2(face: HammeriteFace, points: Vector3[]) -> PackedVector2Array

Public because a decal needs it: a decal clipped out of a wall is coplanar with that wall, so asking for its UV2 here is what lets it be lit by the wall's own bake rather than needing one. HammeriteLightmap UV2 for arbitrary coplanar points on face, reconstructed from the face's baked UV2 (docs Phase 4). The bake maps a vertex's PROJECTED position to UV2 by an axis-aligned scale+offset (HammeriteLightmapPacker.add_face's project_vertices, then _normalize_vertices), so this rebuilds that transform from the BOUNDS of the projected verts and of the baked UV2 and applies it to the piece verts. Deriving it from bounds (not per-vertex pairs) makes it independent of the vertex ORDER get_vertices() returns - an earlier per-index affine version produced garbage UV2 (an all-black bake) whenever that order didn't match bake time. Returns [] pre-bake / when degenerate, so the caller leaves ARRAY_TEX_UV2 unset.

get_entity_instance()

func get_entity_instance(entity: HammeriteEntity) -> Variant

The node built for entity, or null when there is none: not built yet, in a variant that is not active, or a classname no class answers to. An instance that freed itself is still returned until the entity is removed, so check @GlobalScope.is_instance_valid().

create_entity_instance()

func create_entity_instance(entity: HammeriteEntity) -> void

Build the node for entity from its classname, hand it set_map_3d(), set_entity() and set_editor_active(), then emit entity_instance_created. Called for every entity the map has or gains; calling it for one already built leaves the old node behind.

remove_entity_instance()

func remove_entity_instance(entity: HammeriteEntity) -> void

Emit entity_instance_removed and free the node built for entity, if any.

set_skybox()

func set_skybox(skybox: HammeriteSkybox) -> void

Put a sky over this map, or take it away. Both the renderer and the WORLDREP have to be told: whether a face wears the sky material is decided as it is meshed, so a map that had no sky is still wearing flat colour where its apertures are until its brushes are built again. For a change to the sky's own parameters - a different cloud cover, a moon instead of a sun - go through HammeriteSkyRenderer.set_skybox() instead. Nothing needs remeshing for that. Sets the sky of the variant whose sky is in effect (HammeriteMap.get_sky_owner()): the one being looked at, if it has its own.

get_sky_renderer()

func get_sky_renderer() -> HammeriteSkyRenderer

The sky this map is under, or null. Anything that wants to follow the weather - a directional light reading cloud cover, an editor showing a preview - asks here.
